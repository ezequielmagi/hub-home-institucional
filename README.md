# Home institucional con fotografía

Propuesta visual de la home del Hub de Innovación y Transformación en Salud. Conserva los textos y el logo original, con adaptación a escritorio y celular y animaciones de entrada.

Las imágenes son ilustrativas y no representan al equipo real del Hub. Prototipo HTML/CSS/JavaScript para revisión; su implementación final se realizará en WordPress y Elementor.

Abrir index.html o visitar https://ezequielmagi.github.io/hub-home-institucional/.
